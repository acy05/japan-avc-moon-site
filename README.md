# 日本AVC — V47 サイト提案

青い月・雲・水面を巡るサイト提案。最終景色で停止し、自動ループしません。

GitHub Pages: https://acy05.github.io/japan-avc-moon-site/

デザイン提案の公開版です。公式サイトは https://www.ip68.jp/ です。お問い合わせ・技術資料は公式サイトへリンクします。

V44 は Mac ブラウザの 320×568 / 390×844 表示で検証済み。実機 iOS / Android での性能は未検証です。

## V44 読み込み改善

雲データは gzip で約28.9 MBから約2.6 MBへ。月面の法線画像は4Kを保ったlossless WebPへ。展開後のデータ・RGB画素一致を確認済み。形状データの読み込みを並列化。トップ、カメラ経路、終点の制御は維持。`?perf=1` で描画と読み込みのDOM診断値を確認できます。

## V45 初期表示

接近時だけ使用する4Kカラー・法線マップ（合計23,032,873 bytes）の完了を、トップの表示開始条件から分離。原寸データは低優先度で先読み・非同期デコード。早いスクロールは準備完了までトップで待ち、粗い画質への置換をしない。章への直接アクセスは必要なマップを待つ。失敗時は既存の静的表示へ復帰。カメラ経路・描画素材・終点は維持。


## V46 スマホ録画に基づく修正

起動時は別構図の静止画を見せず、同じ青い背景の読み込み表示から描画済みの世界へ。スクロール位置の復元は初期化前に無効化。演出停止では旧静的レイアウト・強制的な章切替を適用せず、現在の景色とレイアウトを保つ。スクロール距離を実測して終点と一致させ、動的な画面高の変更にも進捗を維持。最下部のバウンスを抑制。終点のEXPLORE/FINDと閉幕のリンクの操作領域を確保。スマホの吹き出しを本文・ボタンから離す。

Macブラウザの320×568 / 375×667 / 402×780 / 402×870で該当操作を確認。実機録画を調査資料として使用したが、修正版のiPhone実機再検証は未実施。素材・月面解像度・カメラ経路は変更なし。


## V47 終点のフッターとスマホ再確認

フッターは閉幕の途中から最終景色へ移動し、帰還の完了に合わせて表示。最後のEXPLORE/FINDはフッター上の独立した操作領域へ。スマホの帰還後は冒頭の本文の再表示を省き、月の景色・お礼の吹き出し・ボタン・フッターに整理。冒頭は変更なし。画面高の縮小でブラウザが先にスクロールを補正し、途中へ戻る不具合も修正。直前の進捗から新しいスクロール距離へ変換する。320×568/390×844/1280×800で配置、拡大縮小、停止再開を確認。修正版の実機スマホ検証は未実施。
