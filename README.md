# 日本AVC — V43 サイト提案

青い月・雲・水面を巡るサイト提案。最終景色で停止し、自動ループしません。

## 公開

GitHub Pages: https://acy05.github.io/japan-avc-moon-site/

`main` ブランチのルートを配信します。ビルド不要。ローカル確認は `python3 -m http.server 8080` で起動できます。

デザイン提案の公開版です。公式サイトは https://www.ip68.jp/ です。お問い合わせ・技術資料は公式サイトへリンクします。

V43 は Mac ブラウザの 320×568 / 390×844 表示で検証済み。実機 iOS / Android での性能は未検証です。
