# 日本AVC — V45 サイト提案

青い月・雲・水面を巡るサイト提案。最終景色で停止し、自動ループしません。

## 公開

GitHub Pages: https://acy05.github.io/japan-avc-moon-site/

`main` ブランチのルートを配信します。ビルド不要。ローカル確認は `python3 -m http.server 8080` で起動できます。

デザイン提案の公開版です。公式サイトは https://www.ip68.jp/ です。お問い合わせ・技術資料は公式サイトへリンクします。

V44 は Mac ブラウザの 320×568 / 390×844 表示で検証済み。実機 iOS / Android での性能は未検証です。

## V44 読み込み改善

雲データは gzip で約28.9 MBから約2.6 MBへ。月面の法線画像は4Kを保ったlossless WebPへ。展開後のデータ・RGB画素一致を確認済み。形状データの読み込みを並列化。トップ、カメラ経路、終点の制御は維持。`?perf=1` で描画と読み込みのDOM診断値を確認できます。

## V45 初期表示

接近時だけ使用する4Kカラー・法線マップ（合計23,032,873 bytes）の完了を、トップの表示開始条件から分離。原寸データは低優先度で先読み・非同期デコード。早いスクロールは準備完了までトップで待ち、粗い画質への置換をしない。章への直接アクセスは必要なマップを待つ。失敗時は既存の静的表示へ復帰。カメラ経路・描画素材・終点は維持。
